Anchor Lock — Privacy Policy

Политика конфиденциальности · Privacy Policy
Effective: 2026-05-09 Version 1.0 com.rtk.anchorlockwatch HarmonyOS · Wearable

Настоящая Политика конфиденциальности описывает, какие данные обрабатывает приложение Anchor Lock (далее — «Приложение»), якорная сигнализация для часов Huawei на платформе HarmonyOS, идентификатор пакета com.rtk.anchorlockwatch. Приложение разработано индивидуальным разработчиком Шингирий Павел Евгеньевич (далее — «Разработчик»).

1. Краткое резюме

Приложение работает локально на ваших часах. Оно не имеет серверной части, не передаёт ваши данные на сторонние сервисы, не использует рекламу и не собирает аналитику. Геолокационные данные не покидают устройство.

2. Какие данные обрабатываются

  • Координаты GPS (широта, долгота, точность, отметка времени) — для определения точки якоря и расчёта сноса.
  • Системный язык часов — для выбора между русским и английским интерфейсом.
  • Технические события приложения (постановка якоря, тревога, отключение) — отображаются в журнале последних событий внутри Приложения.

Приложение не собирает: имя, e-mail, номер телефона, идентификаторы устройства за пределами стандартного API HarmonyOS, контакты, фото, биометрические данные, данные о здоровье, историю покупок, рекламные идентификаторы.

3. Цели обработки

  • Сохранение точки якоря по запросу пользователя.
  • Расчёт расстояния от текущего положения до якорной точки.
  • Срабатывание тревоги при выходе за охранный радиус.
  • Локализация интерфейса под язык системы.

4. Хранение данных

Координаты GPS обрабатываются только в оперативной памяти приложения в течение текущей сессии. После выхода из приложения или перезагрузки часов данные о местоположении и история событий стираются. Приложение не использует постоянное хранилище для пользовательских данных.

5. Передача данных третьим сторонам

Приложение не передаёт собранные данные третьим сторонам. В Приложении не используются сторонние SDK, аналитические системы, рекламные сети, облачные сервисы синхронизации. Сетевые запросы Приложение не выполняет.

6. Разрешения операционной системы

  • ohos.permission.LOCATION и ohos.permission.APPROXIMATELY_LOCATION — для получения координат точки якоря и отслеживания сноса. Запрашиваются у пользователя при первой попытке поставить якорь или включить охрану.
  • ohos.permission.VIBRATE — для подачи тревоги вибрацией.

Доступ запрашивается только в режиме foreground (когда приложение открыто). Фоновое отслеживание в текущей версии не используется.

7. Права пользователя

Поскольку Приложение не передаёт данные на серверы и не сохраняет их между сессиями, отдельный запрос на удаление данных не требуется — выход из Приложения автоматически очищает все собранные сведения. Вы можете в любой момент:

  • Отозвать разрешение на геолокацию через системные настройки часов.
  • Удалить Приложение — это удалит все его данные с устройства.
  • Обратиться к Разработчику с вопросом по адресу контактной электронной почты ниже.

8. Дети

Приложение не предназначено для детей младше 13 лет и не направлено на сбор данных от детей. Возрастной рейтинг — 3+ как информационное приложение без сцен жестокости и пользовательского контента, но Приложение требует понимания морской терминологии и не имеет смысла без судна.

9. Безопасность

Поскольку данные не покидают устройство, риск утечки на стороне Разработчика отсутствует. Безопасность хранения данных в оперативной памяти приложения обеспечивается стандартными механизмами изоляции HarmonyOS.

10. Изменения политики

Разработчик может обновлять данную Политику. Актуальная версия всегда доступна по этому URL. Дата вступления в силу указана в начале документа. Существенные изменения будут отражены в описании обновления приложения в AppGallery.

This Privacy Policy describes what data is processed by Anchor Lock (the "App"), an anchor alarm application for Huawei watches running HarmonyOS, package identifier com.rtk.anchorlockwatch. The App is developed by individual developer Shingiriy Pavel Evgenievich (the "Developer").

1. Summary

The App runs locally on your watch. It has no server-side component, transmits no data to third-party services, contains no advertising, and performs no analytics. Location data never leaves the device.

2. Data processed

  • GPS coordinates (latitude, longitude, accuracy, timestamp) — used to capture the anchor point and compute drift.
  • System language of the watch — used to switch the interface between Russian and English.
  • Application events (anchor set, alarm triggered, disarm) — displayed in the in-app event log.

The App does not collect: name, e-mail, phone number, device identifiers beyond the standard HarmonyOS API, contacts, photos, biometric data, health data, purchase history, or advertising identifiers.

3. Purposes of processing

  • Saving the anchor point at the user's request.
  • Computing the distance from the current position to the anchor.
  • Triggering an alarm when the boat exits the guard radius.
  • Localising the interface to the system language.

4. Data storage

GPS coordinates are processed only in the App's volatile memory during the current session. Once the App is closed or the watch is rebooted, all location data and event history are discarded. The App does not use persistent storage for user data.

5. Data sharing with third parties

The App shares no collected data with third parties. It contains no third-party SDKs, analytics systems, advertising networks, or cloud sync services. The App makes no network requests.

6. Operating system permissions

  • ohos.permission.LOCATION and ohos.permission.APPROXIMATELY_LOCATION — used to capture the anchor point and monitor drift. Requested from the user the first time the anchor is saved or monitoring is armed.
  • ohos.permission.VIBRATE — used to deliver alarm haptics.

Permissions are requested in foreground only mode (while the App is open). Background tracking is not used in this version.

7. User rights

Because the App does not transmit data to any server and does not store data across sessions, no separate data-deletion request is required — exiting the App clears all collected information automatically. You may at any time:

  • Revoke location permission via the watch's system settings.
  • Uninstall the App, which removes all its data from the device.
  • Contact the Developer at the e-mail address below with any question.

8. Children

The App is not intended for children under 13 and does not knowingly collect data from children. Content rating is 3+ as a general-purpose tool without violent content or user-generated material, although in practical use the App targets adults familiar with maritime terminology and is not useful without a vessel.

9. Security

Because data does not leave the device, there is no exposure on the Developer's side. Security of in-memory data is provided by the standard HarmonyOS sandbox isolation.
